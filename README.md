# elpude33 · Calculadora PAU

Web para calcular la nota de acceso a la universidad (PAU) y compararla con la nota de corte de distintas carreras.

## Cómo publicarla con GitHub Pages

1. Sube `index.html` a la raíz de este repositorio (ya viene con ese nombre para que GitHub Pages lo sirva directamente).
2. Ve a **Settings > Pages**.
3. En **Source**, elige la rama `main` y la carpeta raíz (`/`).
4. Guarda. En un par de minutos la web estará en `https://tu-usuario.github.io/tu-repo/`.

## Archivos

- `index.html` — la web completa (HTML, CSS y JavaScript en un solo archivo, sin dependencias externas salvo la fuente de Google Fonts).
